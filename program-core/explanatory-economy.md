# Explanatory Economy

A compact or parameter-free formula is not automatically an explanation. The programme distinguishes numerical, functional, structural, and grounding economy so that freedom removed from an equation cannot silently reappear in a representation choice, transport, sector, boundary condition, or branch.

**Numerical economy** counts adjustable dimensionless numbers after units, measured inputs, and initial data have been declared. Calling a fixed number a principle removes it from a fit but does not yet explain it.

**Functional economy** asks whether an arbitrary history, kernel, potential, or response function has been supplied by hand. A rigid finite-parameter history is more falsifiable than a reconstructed free function even before its deeper origin is known.

**Structural economy** counts choices that are not usually displayed as fit parameters: algebra, state family, quotient, transport, generator normalization, extensive measure, source map, sector, boundary condition, and root branch. These choices can carry as much freedom as an explicit coefficient.

**Grounding economy** is strongest. One independently constructed reason makes several otherwise separate facts necessary together, so changing the construction to save one target also changes the others. This is the economy demanded by the programme's principle of sufficient reason.

The four are not interchangeable. A theory can have no fitted constants and no free functions while remaining structurally underdetermined. A phenomenological law can also be useful and sharply falsifiable before it has a grounding explanation.

## Freedom-displacement test

When a proposed derivation removes one apparent freedom, compare the complete choice ledger before and after:

- replacing a free response history with a state family selected because its metric reproduces that history moves freedom into state-space design;
- fixing a scale-state rate while leaving generator normalization or scale soldering free moves freedom into a representation choice;
- obtaining a future class only after selecting a residual sector moves freedom into a global condition;
- eliminating an epoch through an equation with several roots moves freedom into a branch prior; and
- deriving a coupling after using that measured coupling to normalize area moves freedom into the input measure.

If the ledger has not shrunk, the proposal may still be an economical parametrization, but it has not yet supplied the missing sufficient reason.

## Independent-return standard

[[program-core/axioms-and-principles#Programme commitments|PC5]] gives the constitutional rule: a quantity is derived only when neither it, its measured equivalent, nor the target phenomenology was used to construct or normalize the returning object. [[wall-construction-interface/elimination-test|The wall elimination tests]] apply that rule to both the state path and the region on which it is evaluated.

A strong explanatory claim therefore requires:

1. construction of the relevant quotient, state deformation, normalization, and response without the target history;
2. proof that the returned relations follow with no equivalent family of uncounted choices;
3. explicit treatment of nonunit or branch-dependent return values as possible falsifications; and
4. comparison with observations not used to select the construction.

For CST, the rigid pulse has genuine functional economy. Grounding economy begins only if the wall construction and state--geometry bridge return its shape and normalization independently. That audit is summarized by [[causal-scale-theory/realization-map|the CST realization map]].
