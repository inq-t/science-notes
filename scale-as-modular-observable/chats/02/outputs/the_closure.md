## 2. γ = 1

### 2.1 Clause 3 is an identity, not a conjecture

The capacity memorandum lists "the rank-one mode saturates the causal-diamond
capacity" as an unproven clause. It is not. Consider the exponential family
generated by rescaling the modular Hamiltonian,

$$\rho(\lambda) = \frac{e^{-(1+\lambda)K_0}}{Z(\lambda)}, \qquad G^{\rm BKM}_{\lambda\lambda}\Big|_0 = \frac{\partial^2 \ln Z}{\partial\lambda^2}\Big|_0 = \operatorname{Var}(K_0) = \operatorname{Var}(K) = C_E$$

Verified numerically on random modular spectra to 10⁻⁶.

And the horizontal direction **is** the modular-rescaling direction: a Weyl
rescaling changes the diamond radius R, hence T = ħc/2πR, hence β. That is the
soldering, already assumed.

> **Given the soldering, C_⊥,c = C_E,c is an identity of exponential families.**

Clause 3 is discharged.

### 2.2 The reduction

With C_⊥,c = Var(K) and S_c/k_B = ⟨K⟩,

$$\boxed{\;\gamma = \frac{\operatorname{Var}(K)}{\langle K\rangle} = \frac{C}{S} = \frac{d\ln S}{d\ln T}\;}$$

So if S ∝ T^a then γ = a. Verified:

| system | S ∝ | γ |
|---|---|---|
| thermal CFT, d = 4 (bulk matter) | T³ | 3 |
| Schwarzschild / horizon by size | T⁻² | −2 |
| **2D CFT** | **T** | **1** |

$$\gamma = 1 \iff S \propto T \iff \text{a two-dimensional CFT}$$

Among conformal sectors this is unique: γ = d − 1 = 1 ⟺ d = 2.

### 2.3 The horizontal sector is two-dimensional

This is L3a, already established. The codimension-two cut's normal plane is
**two-dimensional and Lorentzian**; modular flow there is the boost
(Bisognano–Wichmann), and Q = P₊ − P₋ is its chirality grading. The transverse
directions are FLRW-symmetry-invariant and **J-even**, so they carry no J-odd
horizontal tangent and drop out of G^⊥ entirely.

> **The horizontal sector is the chiral algebra of the 2D normal plane.**

### 2.4 Cardy closes it

For a 2D CFT at fixed spatial length L, F = −πcL/6β², hence

$$S = \frac{\pi c L}{3}T, \qquad C = T\frac{dS}{dT} = \frac{\pi c L}{3}T = S \qquad\Longrightarrow\qquad \gamma = 1 \qquad\blacksquare$$

**Fixed L is exactly right.** The horizontal deformation is at *fixed
localisation* — that is Chatterjee's fixed-localisation Hessian, and it is the
programme's own definition of horizontal. Varying L instead is the *vertical*
direction, which gives S ∝ R², T ∝ 1/R, γ = −2.

> The vertical and horizontal directions have **different** capacity ratios,
> −2 and +1. Conflating them was the v5.0 error. Keeping them apart is what makes
> the derivation work.
