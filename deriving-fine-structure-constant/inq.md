# Deriving the Fine-Structure Constant

The fine-structure-constant problem is to derive the dimensionless electromagnetic coupling from independently specified algebraic and normalization data, rather than fitting or algebraically re-expressing its measured value. This module is presently an open problem statement: the archived chats preserve exploratory routes, while a canonical derivation would still have to fix the gauge generator, kinetic normalization, renormalization scale and scheme, and independently return the observed low-energy coupling.
