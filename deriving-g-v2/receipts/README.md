# Receipts

The [[deriving-g-v2/receipts/g_closures.py|closure calculation]] checks the declared ledger and crossing arithmetic, running-law comparisons, conditional profile-to-entropy conversion, product-cell dimension bound, qutrit comparison, and finite-cell entropy identity. It also checks the numerical half-log Jones-index comparison; its application to a wall requires a separately proved entropy bound. The script uses the Python standard library and exits nonzero on failure. The [[deriving-g-v2/receipts/receipt-output.txt|stored output]] records an earlier run; current output is obtained by executing the script.

A pass establishes that the checked values follow from the declared constants, cosmology, formulas, and the fully released 2025 direct profile in [[causal-scale-theory/receipts/generalized-background-fit-2025.json]], documented by [[causal-scale-theory/receipts/fit-generalized-background]]. It does not re-run that likelihood, establish the wall construction, validate the conditional map $s_*=1/\mathfrak R_c$, prove a half-log entropy bound for a general subfactor, prove the fossil law, or establish any closure's truth in nature. The equal-partition crossing is asserted only as bookkeeping: it is linear in the matching ratio and therefore a construction, not a discovered centrality.
