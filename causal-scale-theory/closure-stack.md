## Failure localization

- Failure of the wall construction removes the microscopic explanation but leaves a phenomenological two-parameter profile.
- Failure of binary dominance changes the normalized shape.
- Non-rank-one transport or relevant holonomy changes the soldering.
- A scale-dependent $C_\perp(N)$ changes the pulse even if the normalized binary identity survives.
- A different source functional changes the physical density without changing the BKM Hessian.
- A different horizontal temperature changes the amplitude conversion.
- A calculated $\nu\ne1$ or $\mathfrak R_c\ne1$ falsifies only the corresponding unit principle.
- Failure of a stable covariant $T^X_{ab}$ confines the result to homogeneous background kinematics.
- A nonzero residual changes the late-time class without removing the localized response.

This is why [[claim-status|claim status]] is part of the graph: later failure cannot erase earlier exact structure, and earlier exact structure cannot promote a later bridge to theoremhood.
