# Retired Master Sources

This directory preserves the complete byte-for-byte source trees that preceded the versionless Causal Scale Theory module. They are local provenance and cold-storage research material, not competing active modules; current arguments should link to the canonical notes under `causal-scale-theory/`.

The two trees were retired from the workspace root after a final claim, artifact, receipt, and inbound-link audit. Their last active-root state is also recoverable from Git commit `8eef728d80704f6529150afab6e086c5ce58212c`. [[causal-scale-theory/archive|The source archive]] records the reviewed fingerprints and the boundary between preserved history and present canon.

The original v7 ZIP remains inside its exact source tree. [[causal-scale-theory/sources/legacy/unpacked-v7-package/causal_scale_dynamics_v7/README|Its unpacked 65-entry package]] is provided as a convenience mirror so section notes, referee notes, figures, code, and JSON outputs can be reviewed directly in Obsidian. The ZIP, not the mirror, is the single packaged provenance object.

Do not polish these files in place. If they contain a useful idea, migrate that idea into a typed theorem, conditional deduction, conjecture, no-go, commentary, or open-question node in the canonical graph and record the disposition in [[causal-scale-theory/junk-drawer/refactor-plan/retirement-audit|the retirement audit]].
