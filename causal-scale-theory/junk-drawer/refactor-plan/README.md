# Refactor-Plan Archive

This directory preserves the AI-authored inventory, salvage ledger, receipt proposal, quarantine, and migration plan that preceded the reviewed synthesis. They are historical process documents rather than current theory nodes; [[junk-drawer/refactor-plan/refactor-audit|the reviewed audit]] records which recommendations were adopted, corrected, or rejected.

The files remain useful for tracing discarded routes and proposed migrations. In particular, their universal wording about a $\nu=2$ existence bound and their plan to retire the source masters are superseded. No migration or archival instruction in this directory should be executed without a fresh review of the canonical module and inbound links.
