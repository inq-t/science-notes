# Local Source Library

This library makes the `deriving-value-of-g` module self-contained: every external source cited by the canonical notes is mirrored locally, together with the available arXiv source payloads, NIST's machine-readable constants table, four references used only in the immutable chat history, and the gravitational subregion-algebra paper used to test the modular argument. Inclusion records relevance to a proof obligation, not endorsement of every claim in a source.
