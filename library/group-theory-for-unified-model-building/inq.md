# Group Theory for Unified Model Building

Slansky collects Lie-group representation conventions, tensor products, subgroup branchings, and embedding data used in unified model building. Table 46 records the \(F_4\) branching under \(SU(3)\times SU(3)\) used to decompose the exceptional flag tangent and normal representations.

## Source

Richard Slansky, *Physics Reports* **79** (1981), 1--128.
