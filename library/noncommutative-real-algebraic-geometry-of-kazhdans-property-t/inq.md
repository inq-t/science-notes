# Noncommutative Real Algebraic Geometry of Kazhdan's Property (T)

Narutaka Ozawa characterizes Kazhdan property \((T)\) through sums of Hermitian squares in a real group algebra. For the group Laplacian associated with a finitely supported symmetric generating probability measure, property \((T)\) is equivalent to a certificate \(\Delta^2-\kappa\Delta=\sum_j\xi_j^*\xi_j\) for some \(\kappa>0\). The argument connects representation-uniform spectral gaps with noncommutative positivity.

- Author: Narutaka Ozawa.
- Preprint: 2013.
- Source and version history: [arXiv:1312.5431](https://arxiv.org/abs/1312.5431).
