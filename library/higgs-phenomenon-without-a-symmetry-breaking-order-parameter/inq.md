# Higgs Phenomenon Without a Symmetry-Breaking Order Parameter

Jürg Fröhlich, Giovanni Morchio, and Franco Strocchi give a gauge-invariant account of the Higgs phenomenon in which the physical particle content is described by local gauge-invariant fields rather than by a gauge-dependent symmetry-breaking order parameter. The result separates the observable spectral phenomenon from the conventional gauge-fixed narrative.

- Authors: Jürg Fröhlich, Giovanni Morchio, Franco Strocchi
- Published: *Physics Letters B* **97** (1980), 249--252
- DOI: [10.1016/0370-2693(80)90594-8](https://doi.org/10.1016/0370-2693(80)90594-8)
- Local artifacts: none
