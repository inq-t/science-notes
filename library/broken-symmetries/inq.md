# Broken Symmetries

Goldstone, Salam, and Weinberg present proofs of the conjecture now called Goldstone's theorem: if a continuous transformation leaves the Lagrangian invariant, then either the vacuum is also invariant or the theory contains massless spin-zero particles.

## Metadata

- **Authors:** Jeffrey Goldstone, Abdus Salam, and Steven Weinberg.
- **Received:** 16 March 1962.
- **Published:** 1 August 1962.
- **Journal:** *Physical Review* **127** (3), 965--970.
