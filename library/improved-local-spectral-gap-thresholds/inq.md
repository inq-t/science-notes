# Improved Local Spectral Gap Thresholds for Lattices of Finite Dimension

Anshu derives inverse-square finite-region thresholds for frustration-free lattice Hamiltonians using detectability and coarse-grained ground-space projections. The argument treats open and periodic boundaries without requiring translation invariance.
