# Finding the Observed Information Matrix When Using the EM Algorithm

Thomas A. Louis derives the observed-information matrix of an incomplete-data likelihood from complete-data scores and Hessians. The resulting missing-information decomposition expresses the observed score through conditional expectation and subtracts a conditional score covariance from complete information.
