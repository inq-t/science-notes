# On an Inequality for Modified Bessel Functions

R. P. Soni proves a strict order inequality for modified Bessel functions of the first kind. In the positive-order range needed for compact-group Wilson kernels, it gives $I_{\nu+1}(x)<I_\nu(x)$ for $x>0$, hence strict decrease of the representation coefficients as the order increases.

## Metadata

- **Author:** R. P. Soni.
- **Published:** April 1965.
- **Journal:** *Journal of Mathematics and Physics* **44** (1965), 406--407.
- **DOI:** [10.1002/sapm1965441406](https://doi.org/10.1002/sapm1965441406).
- **Reference check:** [NIST DLMF section 10.37](https://dlmf.nist.gov/10.37) records the corresponding strict monotonicity in the order for fixed positive argument.
