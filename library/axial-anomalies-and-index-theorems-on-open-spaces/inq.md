# Axial Anomalies and Index Theorems on Open Spaces

Constantine Callias derives resolvent trace formulas and index theorems for Dirac operators on noncompact odd-dimensional spaces using the axial anomaly. Applications include the index of a Dirac operator for arbitrary isospin in the background of static \(SU(2)\) monopoles and formulas for associated determinants.

- Author: Constantine Callias
- Published: 1978
- Journal: *Communications in Mathematical Physics* **62**, 213--234
- DOI: [10.1007/BF01202525](https://doi.org/10.1007/BF01202525)
- Record: [CERN Document Server](https://cds.cern.ch/record/400562)
